# PURPOSE
This project was made to show how dikstra choose the shortest path in a undirected graph, the prograam was made using java.
\
## Controls:
[W] = Insert mode
[E]= Edge mode [R] = Insert
[G] = Create Random Graph
[Q] = Step by Step mode
### RANDOM GRAPH
creates random graph when inputting numbers in the textbox
### INSERT MODE
allows for the addition and removal of nodes
### EDGE MODE
allows for the addition and removal of edges. Also allows weight edifing of edges VIEW MODE
allows for the Dijkstra's algorithm execution
### STEP MODE
allows for the Dijkstra's algorithm to run sequentially
### LEFT MOUSE FUNCTIONS:
INSERT MODE: adds node in the position of the mouse
### EDGE MODE: adds connection when two nodes are chosen
Weight editing can be done by clicking the edge weight
- VIEW MODE: performs Dijkstra's algorithm when two nodes are chosen
- STEP MODE: perform Dijkstra's algorithm sequentially when two nodes are chosen
- RIGHT MOUSE FUNCTIONS:
- INSERT MODE: removes node when right mouse is clicked
- EDGE MODE: removes connection when two nodes are chosen
- VIEW MODE: resets the view (removes selection)
